## 📌 Özellikler

- 🎯 **Kişiselleştirilmiş Öğrenme Planı:** Hedefinize, seviyenize ve günlük çalışma vaktinize özel yapay zeka tarafından oluşturulan hafta hafta müfredat.
- 💡 **Tamamen Ücretsiz Kaynaklar:** YouTube eğitimleri, resmi dokümantasyonlar ve ücretsiz makalelerle desteklenen içerik önerileri.
- ⚡ **Yıldırım Hızında Yanıt:** Groq Cloud LLaMA 3.3 70B modeli sayesinde saniyeler içinde müfredat oluşturma.
- 📚 **Yol Haritası Geçmişi:** Oluşturulan tüm planları Supabase veritabanında saklama ve dilediğiniz zaman tekrar inceleme / silme.
- 🔐 **Güvenli Kimlik Doğrulama:** Supabase Auth ile güvenli kullanıcı kaydı ve giriş sistemi.
- 🛡️ **Güvenli Sunucu Mimarisi:** Web sürümünde Groq API anahtarı istemciye (tarayıcıya) asla sızdırılmaz; Next.js API Route Handler üzerinden güvenle çağrılır.

## 🛠️ Kurulum ve Başlangıç

### 1. Depoyu Klonlayın
```bash
git clone https://github.com/AhmetEmirCetin/SkillBridge.git
cd SkillBridge
```

---

### 2. Supabase Veritabanı Kurulumu (SQL)
Supabase panelinizde (`SQL Editor`) aşağıdaki sorguyu çalıştırarak gerekli tabloları oluşturun:

```sql
-- 1. Profiller Tablosu
CREATE TABLE public.profiles (
  id UUID REFERENCES auth.users(id) ON DELETE CASCADE PRIMARY KEY,
  email TEXT NOT NULL,
  full_name TEXT,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL
);

-- 2. Yol Haritaları Tablosu
CREATE TABLE public.roadmaps (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  user_id UUID REFERENCES auth.users(id) ON DELETE CASCADE NOT NULL,
  goal TEXT NOT NULL,
  level TEXT NOT NULL,
  hours_per_day TEXT NOT NULL,
  location TEXT,
  content TEXT NOT NULL,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL
);

-- Row Level Security (RLS) Etkinleştirme
ALTER TABLE public.profiles ENABLE ROW LEVEL SECURITY;
ALTER TABLE public.roadmaps ENABLE ROW LEVEL SECURITY;

-- Güvenlik Politikaları (Kullanıcı yalnızca kendi verisini görür ve yönetir)
CREATE POLICY "Kullanıcılar kendi profillerini görebilir" 
  ON public.profiles FOR ALL USING (auth.uid() = id);

CREATE POLICY "Kullanıcılar kendi yol haritalarını yönetebilir" 
  ON public.roadmaps FOR ALL USING (auth.uid() = user_id);
```

---

### 3. Web Uygulamasını Çalıştırma (Next.js)

1. `web` klasörüne geçin ve bağımlılıkları yükleyin:
   ```bash
   cd web
   npm install
   ```

2. `.env.local` dosyasını oluşturup API anahtarlarınızı girin:
   ```bash
   cp .env.example .env.local
   ```
   *İçeriği:*
   ```env
   GROQ_API_KEY=gsk_your_groq_api_key_here
   NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=your-supabase-anon-key
   ```

3. Geliştirme sunucusunu başlatın:
   ```bash
   npm run dev
   ```
   Tarayıcınızda [http://localhost:3000](http://localhost:3000) adresini açın.

---

### 4. Mobil Uygulamayı Çalıştırma (Expo / React Native)

1. `mobile` klasörüne geçin ve bağımlılıkları yükleyin:
   ```bash
   cd mobile
   npm install
   ```

2. `.env` dosyasını oluşturun:
   ```bash
   cp .env.example .env
   ```
   *İçeriği:*
   ```env
   EXPO_PUBLIC_GROQ_API_KEY=gsk_your_groq_api_key_here
   EXPO_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
   EXPO_PUBLIC_SUPABASE_ANON_KEY=your-supabase-anon-key
   ```

3. Expo geliştirme sunucusunu başlatın:
   ```bash
   npx expo start
   ```
   *Expo Go uygulaması ile QR kodu taratarak telefonunuzda anında test edebilirsiniz.*

## 🔒 Güvenlik Notu

- Asla gerçek `.env`, `.env.local` veya API anahtarlarınızı Git reposuna yüklemeyin.
- `.gitignore` dosyası gizli anahtarlarınızı koruyacak şekilde yapılandırılmıştır.
- API anahtarlarınızı [Groq Cloud Console](https://console.groq.com) ve [Supabase Dashboard](https://supabase.com) üzerinden ücretsiz edinebilirsiniz.
